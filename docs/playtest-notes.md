# Playtest checklist (self-review)

このファイルは **1 セッション通しでプレイして fun を自己検証する** ための
チェックリスト雛形。プレイ結果のメモはここにはコミットしない。気づいた
ことを次 PR の issue / spec に反映する。

## Core loop

- [ ] 「探す → 組む → 撃つ → 結果を見る」のリズムは心地いいか？
- [ ] 毎ターン「何しよう」と悩む余地があるか？ それとも自明？
- [ ] スペルを撃った後の VFX で「何が起きたか」が一発で分かるか？

## Combo discovery

- [ ] 「これ強いじゃん」という発見はあったか？ 具体的にどの組み合わせ？
- [ ] 同種スペル degradation は体感できたか？
- [ ] バケツリレー (line → 3way → line 等) は意図通りに見えたか？

## Threat / tension

- [ ] 敵が追跡して殴ってくる緊張感はあるか？ 物足りないか？
- [ ] ダメージを受けたときに焦るか？ 無感動か？
- [ ] 勝利／敗北の瞬間に感情が動くか？

## Legibility

- [ ] 「何故そうなった」が分からない場面はあったか？ どこ？
- [ ] マナ管理の判断は意味があるか？
- [ ] スペルの効果範囲を予測できたか？

## 次の一手

- [ ] 最優先で直したい不満 3 つ
- [ ] 次に欲しい機能 3 つ (range preview / tooltips / 敵アーキタイプ等)
